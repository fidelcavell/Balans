# Balans

A personal finance app built for iOS that helps users stay on top of their budget. Users can log income and expenses, categories transactions, and visualize their financial habits through interactive charts — all stored locally with SwiftData for full offline support capability.

## Features

- Log your incomes and expenses
- Home-screen widget to display current budget information
- Interactive Charts visualization of your incomes and expenses
- Support fully-offline usage

## Requirements

- Xcode 26.0 or later
- iOS 26.5+ deployment target

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/fidelcavell/Balans.git
   git checkout release/no-ai-powered
   ```

2. Switch to "release/no-ai-powered" branch
   ```bash
   git checkout release/no-ai-powered
   ```
   
3. Open the project in Xcode
   ```bash
   open ExpenseTracker.xcodeproj
   ```

4. Build and run
   - Select a simulator or connected device
   - Press `Cmd + R`
